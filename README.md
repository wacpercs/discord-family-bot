# 🤖 Discord Bot для управления семьёй на GTA 5 RP

Полнофункциональный Discord бот для управления семьёй на GTA 5 RP сервере с системой заявок, предупреждений, отчётов о мероприятиях и управлением участниками.

## 📋 Возможности

### ✨ Основные функции:
- 📝 **Система заявок** - приём и обработка заявок на вступление в семью
- ⚠️ **Система предупреждений** - выдача варнов с автоматическим исключением при 3 предупреждениях
- 📋 **Отчёты о мероприятиях** - участники могут отправлять отчёты о проведённых ивентах
- 👥 **Управление участниками** - профили, список семьи, исключение участников
- 📊 **Статистика** - рейтинг организаторов, общая статистика семьи
- 💾 **База данных** - все данные сохраняются в SQLite

### 📦 Модули (Cogs):
1. **applications.py** - Обработка заявок на вступление
2. **warns.py** - Система предупреждений
3. **reports.py** - Отчёты о мероприятиях
4. **members.py** - Управление участниками
5. **utils.py** - Вспомогательные команды

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка бота

1. Переименуйте `.env.example` в `.env`
2. Заполните файл `.env` своими данными:

```env
DISCORD_TOKEN=ваш_токен_бота
GUILD_ID=id_вашего_сервера
APPLICATIONS_CHANNEL_ID=id_канала_для_заявок
REPORTS_CHANNEL_ID=id_канала_для_отчётов
LOGS_CHANNEL_ID=id_канала_для_логов
FAMILY_ROLE_NAME=🏠 Семья
```

### 3. Получение токена бота

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications)
2. Нажмите "New Application" и дайте название боту
3. Перейдите во вкладку "Bot"
4. Нажмите "Add Bot"
5. Скопируйте токен (Token) и вставьте в `.env`
6. Включите следующие **Privileged Gateway Intents**:
   - ✅ PRESENCE INTENT
   - ✅ SERVER MEMBERS INTENT
   - ✅ MESSAGE CONTENT INTENT

### 4. Приглашение бота на сервер

1. Перейдите во вкладку "OAuth2" → "URL Generator"
2. Выберите следующие **scopes**:
   - ✅ `bot`
   - ✅ `applications.commands`
3. Выберите **права** (Bot Permissions):
   - ✅ Manage Roles
   - ✅ Manage Nicknames
   - ✅ Kick Members
   - ✅ Send Messages
   - ✅ Embed Links
   - ✅ Attach Files
   - ✅ Read Message History
   - ✅ Add Reactions
   - ✅ Use Slash Commands
4. Скопируйте сгенерированную ссылку и откройте её в браузере
5. Выберите ваш сервер и пригласите бота

### 5. Получение ID каналов и сервера

Включите режим разработчика в Discord:
1. Настройки → Расширенные → Режим разработчика (включить)
2. Правый клик на сервере → "Копировать ID" - это GUILD_ID
3. Правый клик на канале → "Копировать ID" - это CHANNEL_ID

### 6. Создание роли семьи

На вашем Discord сервере создайте роль с названием `🏠 Семья` (или измените название в `.env`)

### 7. Запуск бота

```bash
python bot.py
```

Если всё настроено правильно, вы увидите:
```
╔══════════════════════════════════════╗
║  Бот успешно запущен!                ║
║  Имя: Ваш Бот                        ║
║  ID: 123456789                       ║
╚══════════════════════════════════════╝
✅ Синхронизировано X команд(ы)
```

## 📚 Список команд

### Для всех участников:
- `/заявка` - Подать заявку на вступление в семью
- `/отчёт` - Отправить отчёт о проведённом мероприятии
- `/мои_отчёты` - Посмотреть свои отчёты
- `/warns` - Посмотреть свои предупреждения
- `/профиль` - Посмотреть профиль участника
- `/список_семьи` - Показать всех участников семьи
- `/топ_организаторов` - Топ организаторов мероприятий
- `/помощь` - Показать список команд
- `/инфо` - Информация о боте
- `/пинг` - Проверить задержку бота

### Для модераторов (требуется право "Manage Roles"):

- `/установить_ник` - Установить игровой ник участнику

### Для администраторов:
- `/unwarn` - Снять предупреждение с участника
- `/clearwarns` - Очистить все предупреждения участника
- `/исключить` - Исключить участника из семьи
- `/статистика` - Общая статистика семьи

## 🔧 Настройка под себя

### Изменение названия роли семьи
В файле `.env` измените:
```env
FAMILY_ROLE_NAME=Ваше Название
```

### Изменение лимита предупреждений
В файле `cogs/warns.py` найдите строку:
```python
if warn_count >= 3:
```
Измените `3` на нужное число.

### Добавление новых команд
1. Создайте новый файл в папке `cogs/`
2. Используйте шаблон:
```python
import discord
from discord.ext import commands
from discord import app_commands

class YourCog(commands.Cog):
    def __init__(self, bot):
        self.bot = bot
    
    @app_commands.command(name="ваша_команда")
    async def your_command(self, interaction: discord.Interaction):
        await interaction.response.send_message("Ответ")

async def setup(bot):
    await bot.add_cog(YourCog(bot))
```

## 🐛 Решение проблем

### Бот не отвечает на команды
1. Убедитесь, что включены все Privileged Gateway Intents
2. Проверьте, что бот имеет права на использование slash-команд
3. Подождите несколько минут после первого запуска (синхронизация команд)

### Ошибка "Application did not respond"
- Проверьте, что бот запущен и онлайн
- Убедитесь, что команды синхронизированы (смотрите лог при запуске)

### Бот не может выдавать роли
- Убедитесь, что роль бота выше роли, которую он пытается выдать
- Проверьте права "Manage Roles" у бота

### Канал не найден
- Проверьте правильность ID каналов в `.env`
- Убедитесь, что бот имеет доступ к этим каналам
