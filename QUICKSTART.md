# 🚀 БЫСТРЫЙ СТАРТ - Discord Bot для GTA 5 RP семьи

## ⚡ За 5 минут до запуска

### 1️⃣ Установите зависимости
```bash
pip install -r requirements.txt
```

### 2️⃣ Создайте бота в Discord
1. Откройте: https://discord.com/developers/applications
2. "New Application" → придумайте название
3. Вкладка "Bot" → "Add Bot" → скопируйте **TOKEN**
4. Включите в Bot настройках:
   - ✅ PRESENCE INTENT
   - ✅ SERVER MEMBERS INTENT  
   - ✅ MESSAGE CONTENT INTENT

### 3️⃣ Пригласите бота на сервер
1. Вкладка "OAuth2" → "URL Generator"
2. Выберите: `bot` + `applications.commands`
3. Права: Administrator (или нужные вручную)
4. Скопируйте ссылку → откройте → выберите сервер

### 4️⃣ Настройте .env файл
```bash
# Переименуйте .env.example в .env
mv .env.example .env

# Или на Windows просто переименуйте файл
```

Заполните .env:
```env
DISCORD_TOKEN=вставьте_токен_бота_сюда
GUILD_ID=id_вашего_сервера
APPLICATIONS_CHANNEL_ID=id_канала_для_заявок
REPORTS_CHANNEL_ID=id_канала_для_отчётов
LOGS_CHANNEL_ID=id_канала_для_логов
FAMILY_ROLE_NAME=🏠 Семья
```

### 5️⃣ Получите ID (включите режим разработчика в Discord)
Настройки → Расширенные → Режим разработчика → Включить

Теперь:
- Правый клик на **сервере** → Копировать ID = `GUILD_ID`
- Правый клик на **канале** → Копировать ID = `CHANNEL_ID`

### 6️⃣ Создайте роль семьи
На сервере создайте роль `🏠 Семья` (или измените название в .env)

### 7️⃣ Запустите бота

**Linux/Mac:**
```bash
./start.sh
# Или с установкой зависимостей:
./start.sh --install
```

**Windows:**
```cmd
start.bat
REM Или с установкой зависимостей:
start.bat --install
```

**Вручную:**
```bash
python bot.py
```

## 📝 Основные команды

- `/заявка` - Подать заявку на вступление
- `/отчёт` - Отправить отчёт о мероприятии
- `/warn` - Выдать предупреждение (модератор)
- `/профиль` - Посмотреть профиль
- `/помощь` - Все команды

## 🐛 Проблемы?

**Бот не отвечает:**
- Подождите 2-3 минуты после запуска
- Проверьте, что включены все Intents в настройках бота

**Канал не найден:**
- Проверьте правильность ID в .env
- Убедитесь, что бот видит канал

**Нет прав:**
- Роль бота должна быть выше роли семьи
- Проверьте права бота на сервере
